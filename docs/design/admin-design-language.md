# Admin 设计语言

> token / 主题 / 字体回退链 / 组件质感的定义统一在 `@repo/ui`（见
> [`design-system.md`](./design-system.md)）；本文记录 **admin 应用层**的设计语言：
> 怎么决定主次、怎么用面层、字号与间距怎么取、组件怎么长。
> 两者冲突时以 `packages/ui/src/globals.css` 的变量为准。

## 1. 定位与基调

- **产品**：Billy Cli（一套模板，全栈直达），开发者工具。
- **受众**：开发者 / 运维 / 运营。
- **基调**：亮色优先的 devtool 风（Linear / Vercel 式克制精确），完整深色模式。
- **一句话**：中性色打底、品牌色点睛、状态色说话，靠面层明度而不是线条组织信息。

## 2. 设计原则

1. **内容有主次**（设计哲学，不是排版技巧）：先回答「这一页为什么存在」，再决定谁占大、谁靠上。
   - **主内容**：用户第一眼要的结论或要操作的对象，占最大面积、最靠上；
   - **次内容**：支撑判断的上下文（趋势、分布、明细），排在主内容之下；
   - **辅助内容**：元信息与规模数字（实例 ID、时间槽、总数、时间戳），收成一行小字放底部或角落。
   - 表达手段依次是：**位置（上→下）→ 面积（大→小）→ 字号字重 → 颜色**。
2. **微色阶表达层次**：页面底 / 侧栏 / 卡片 / 卡内磁贴按明度分档（见 §5），
   **不画结构边框、不叠投影**。表单控件自身的描边属可用性，不在此列。
3. **不用渐变**：背景晕染、卡片晕染、图表填充、水位填充一律平涂。
4. **单一强调色**：品牌靛紫只做品牌触点（焦点环、侧栏激活态、品牌标记、图标色片、图表主色）；
   语义色只表达状态，不当装饰。
5. **状态可读**：状态永远「颜色 + 文案」成对出现，不靠单一色相传递信息（色弱可读）。
6. **克制动效**：只有颜色过渡（150ms）与数字滚动；无循环动画（运行中的呼吸灯例外）。
7. **可访问性**：正文对比 ≥ 4.5:1；语义色取到 AA 档位；尊重 `prefers-reduced-motion`。

## 3. 页面配方（内容主次怎么落）

| 页面 | 主内容 | 次内容 | 辅助内容 |
| --- | --- | --- | --- |
| 控制台 | 运行状态（依赖健康 + 未恢复告警） | AI 用量趋势 | 用户 / 规则 / 记录数（一行） |
| 监控状态 | 关键水位 + 越线结论 | QPS 趋势、采集异常、指标健康度 | 实例、时间槽、指标数、规则数 |
| 监控指标 | 当前值与最近窗口 | 历史窗口列表 | 指标 key、单位、区间 |
| 告警记录 / 规则 / 用户 | 表格本身与主列 | 搜索与筛选 | 分页、ID、时间戳 |
| 会话审计 | 会话列表（标题） | 搜索、已删除开关 | 会话 ID、轮数、token、时间 |
| AI 会话 | 对话流与输入框 | 会话历史列表、右侧运行面板 | 轮数、相对时间、token |

判断标准：把页面截图缩到很小，还能第一眼读出「这里在说什么」的就是主内容；读不出来的应当下沉。

## 4. 色彩

| 角色 | token | 用途 |
| --- | --- | --- |
| 正文 / 强调数字 | `--foreground` | 主信息文字 |
| 次级文字 | `--muted-foreground` | 说明、标签、辅助值 |
| 品牌 | `--brand` | 焦点环、侧栏激活、品牌标记、图标色片、图表主色 |
| 成功 | `--success` | 健康、已恢复、同比向好 |
| 警告 | `--warning` | 阈值接近、陈旧、待关注 |
| 错误 | `--destructive` | 越线、失败、未恢复告警 |
| 信息 | `--info` | 中性状态（类型、通道、分类） |
| 主按钮 | `--primary` | 近黑（深色反白），刻意避开 antd 蓝 |

- 图表色阶：`--chart-1..5`（靛紫 → 青 → 琥珀 → 品红 → 石板灰）。
- `Tag` 只有 `default / success / warning / error / processing` 五个语义名；
  历史色名（blue / cyan / gold / purple …）是别名，已统一折算到语义色与品牌色。

## 5. 面层（微色阶）

浅色由浅到深（深色模式反向逐级提亮）：

| 面 | token | 典型用途 |
| --- | --- | --- |
| 卡片 | `--card` | 内容卡、表格容器、弹窗（最亮） |
| 一级 | `--surface-1` | 页面内的大区块、卡内分区 |
| 二级 | `--surface-2` | 表头、卡内磁贴、按钮组底 |
| 三级 | `--surface-3` | 侧栏导轨、更深一层的磁贴 |
| 四级 | `--surface-4` | 指标磁贴、选中态 |
| 页面底 | `--background` | 页面背景（比卡片深，卡片自带抬升） |

规则：**同一块内容最多叠三层**（页面底 → 卡片 → 卡内磁贴），再深就改用留白或分组，不要继续加层。

## 6. 排版

| 层级 | 取值 | 用途 |
| --- | --- | --- |
| 巨数字 | `text-2xl / 3xl` + `font-heading font-medium tabular-nums` | 控制台 / 监控的结论数字 |
| 页面标题 | `text-lg` + `font-heading font-medium tracking-tight` | `PageToolbar` 的 title |
| 区块标题 | `text-sm / text-base` + `font-medium` | 卡片标题、分节标题 |
| 正文 | `text-[13px]` | 表格、列表、正文 |
| 说明 | `text-xs` + `text-muted-foreground` | 描述、提示 |
| 辅助 | `font-mono text-[11px]` + `text-muted-foreground` | ID、key、时间戳、耗时 |

- 数字统一 `tabular-nums`（设计系统全局已开）；大数字走 `font-heading`，标识符走 `font-mono`。
- 同一行最多一个 `font-medium`。
- 正文不再用纯黑 `#000`，一律 `--foreground`（带一丝冷调）。

## 7. 圆角与间距

- 圆角：卡片 / 面板 `rounded-xl`（部分大区块 `rounded-2xl`）、磁贴与输入框 `rounded-lg`、
  按钮 / 小控件 `rounded-md`、状态胶囊 `rounded-full`。不混用同一层级的不同圆角。
- 页面留白：`p-4 sm:p-8`；区块间距 `gap-4`~`gap-5`；卡片内边距 `p-4`~`p-5`；
  表格行高由 `py-2.5` 固定，不按内容浮动。

## 8. 组件规范

- **页头**：统一用 `PageToolbar`（`title` / `description` / `extra` / 搜索区），不手写 `<h1>`。
- **卡片**：`bg-card`、无边框、无投影、`rounded-xl`；标题 `text-sm font-medium`，描述 `text-xs muted`。
- **表格**：白卡容器 + 灰表头（`bg-surface-2/60`）+ 行只留 hover（无斑马纹、无行分隔线）。
- **标签**：语义五色；极淡底 + 语义前景，不用强彩色块。
- **状态**：`圆点 + 文案` 或 `Tag`；颜色只给结论（越线 / 未恢复 / 失败）。
- **空态**：居中，一句主文案 + 一句怎么办的说明；不要只放一个灰字。
- **表单**：控件必须有**看得见的边界**（这是可用性，不是装饰）——输入框 / 文本域 / 下拉 /
  复选框用「比所在面板深一档的面色（`surface-3`）+ 1px 内描边（`ring-1 ring-inset ring-border`）」，
  关闭态开关用 `surface-4`；聚焦走品牌色焦点环；错误文案 `text-destructive` 且带具体原因。
  只在页面上给一档 2% 的面色差（如白卡片上的 `surface-2`）是不合格的：弹窗里等于没有形状。
  控件**一律用组件库**：`Input` / `Textarea` / `Select` / `DictSelect` / `Combobox` / `Switch` /
  `Checkbox` / `RadioGroup` / `Label`；不写原生 `<select>` / `<input>` / `<button>`。
  原生 `<form>` 只在需要回车提交时保留（语义容器，不是控件）。
- **图表**：无网格线、无边框；阈值线用 `--warning` 虚线；tooltip 无边框、用投影（浮层允许投影）。

## 9. 壳组件（`apps/admin/src/components`）

- **AppSider**：悬浮式侧栏（`variant="floating"`）—— 白面圆角胶囊，四周留 12px，靠面层差浮起、
  不叠投影；logo = 品牌靛紫方块（`bg-brand`）+ 字标 + mono 副标「admin console」；
  菜单激活态 = 品牌色淡底（`--sidebar-accent`）+ 品牌前景色。折叠后是一条图标导轨，仍是同一块胶囊。
- **AppHeader**：左侧页面标题（**与侧栏菜单同源**：`menuTitleOf` 由 `MENU_ITEMS` 推导，
  新增页面只改菜单即可，标题不会空着）+ 右侧主题切换；底色 `bg-background/85` + 轻模糊。
- **登录页**：左栏品牌叙事 + 纯面色底，右侧白面表单卡；品牌标记同 `bg-brand`，不做装饰渐变。
- **AI 会话页**：独立布局（全窗口工作台）；左侧会话列表栏 `bg-surface-3`，
  中间对话区 `bg-background`，右侧运行面板按需展开。

## 10. 主题切换

- 存储键 `billy-admin-theme`（light / dark / system），默认跟随系统。
- `layout.tsx` 内联引导脚本在水合前设置 `.dark`，避免深色模式刷新闪烁（FOUC）。
- 系统偏好变化时 system 模式自动跟随；手动选择后以手动为准。
- 深色下不额外加彩色底：统计块等浅色平涂在深色模式退回中性面（`dark:bg-none dark:bg-surface-2`）。

> 前台 `apps/web` **目前没有**主题切换 —— 只有 admin 会挂 `.dark`。

## 11. 新增页面自查清单

- [ ] 先写清这一页的主内容 / 次内容 / 辅助内容，再动手排
- [ ] 页头用 `PageToolbar`，列表用 `DataTable` / `DataList`，弹窗用 `ModalForm` / `DrawerForm`
- [ ] 选项 ≤4 的枚举用 `SegmentedControl`，不要用下拉
- [ ] 弹窗 / 抽屉的头尾固定，只有内容区滚动
- [ ] 视觉取值只用语义 token，不写 `bg-blue-500` 这类调色板类（`pnpm check:ui` 会拦新增）
- [ ] 不加结构边框、不加卡片投影、不用渐变；层次用面层明度差
- [ ] 同一行最多一个 `font-medium`；ID / 时间 / 路径用 `font-mono`
- [ ] 状态「颜色 + 文案」成对出现
- [ ] 表单控件全部来自组件库（原生 `<select>` / `<input>` / `<button>` 一个不留）
- [ ] 浅色与深色模式都过一遍（`ThemeToggle` 切换验证）
- [ ] 主按钮 / 表单 / 焦点环对比度达 AA
