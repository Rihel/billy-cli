# 2026-10-22 开发记录

**后台「不再一片灰白」**：上一轮去掉颜色与边框后，页面底 / 卡片 / 侧栏的明度差只有 1.3%，
整屏零彩度，读不出层次。本轮在中性色上注入一丝冷调（`--background: oklch(0.962 0.006 265)`，
surface 阶梯 0.004~0.008 chroma），把面层差拉到 2%~3%，卡片改纯白上浮、侧栏沉一档做导轨；
品牌靛紫 `--brand` 回到界面主体：侧栏激活态（`color-mix` 淡底）、品牌标记、统计卡图标色片、
图表主色；`--chart-1..5` 改成靛紫 / 青 / 琥珀 / 品红 / 石板灰；语义色用于服务状态胶囊与告警。

**组件连带**：Card 改 `bg-card`（纯白对页面底就是一阶微色阶）；DataTable 改「白卡 + 灰表头 + 只留 hover」（去掉斑马纹）；
TableRow hover `bg-surface-2/70`；AppHeader 改 `bg-background/85 + backdrop-blur`。

**页面**：控制台统计块改「彩色图标 + 标签 + mono 大数字」，浅色下平涂 6%~7% 色块、深色下退回
中性面；服务状态改语义色胶囊；AI 用量柱状 / 环图走图表色阶。监控状态页拖拽卡改白卡，水位图改
半透明平涂 + 细环，修掉 `margin.left: -18` 把 Y 轴刻度切掉的问题。登录页品牌标记改 `bg-brand`、
表单卡白面上浮。

**内容主次（页面级）**：控制台把「运行状态（依赖健康 + 未恢复告警）」提到首屏做主内容，AI 用量降为次内容，
用户 / 规则 / 记录数收成底部一行辅助数字；监控状态页把「关键水位 + 越线结论」提到最上，
QPS 趋势 / 采集异常 / 指标健康度居中，运行概览（实例、时间槽、指标数、规则数）沉到底部。

**信息主次（行内）**：按「每个页面都要有主次」的原则做了一轮列表页整理 —— 规则名 / 邮箱 / 告警规则名做
主信息（`font-medium`），时间戳 / metric key / 实例主体降为辅助（mono 11px + muted），耗时与区间
用 `tabular-nums`；监控指标的「最近值」列表把最新窗口置为主行、历史窗口降为背景，条形改品牌色；
会话审计页补回页面内边距（此前满幅贴边）；页头标题改为从侧栏 `MENU_ITEMS` 推导（`menuTitleOf`），
此前告警记录 / 监控指标 / 工具配置等页面的页头是空的。

**不用边框 / 不用投影**：按「微色阶表达层次」的原则，撤掉统计卡的 ring 与投影、Card 与表格容器的
投影、登录页卡片的悬浮阴影、logo 的彩色投影、水位图外圈描边 —— 层次只靠页面底 0.962 → 卡片 1.0 →
卡内磁贴 0.972 的面层阶梯；表单控件自身描边保留（可用性）。

**不用渐变**：按用户要求，后台一律不用渐变 —— 统计卡的品牌晕染改平涂、登录页左栏光晕删除、
水位图渐变填充改半透明平涂、面积图渐变填充改 `fillOpacity` 平涂。

**守卫与文档**：`tokens.test.ts` 的「派生层不许抄字面量」允许基于 `var()` 的 `color-mix`，
`chart-1` / `sidebar-primary` 目标值改 `var(--brand)`；`design-system.md` 补 §11、
`admin-design-language.md` 同步视觉取值与壳组件描述。

**验证**：`pnpm typecheck`（5 包）、`pnpm check:ui`、`pnpm --filter @repo/ui test`（71 项）通过；
用无头 Chrome + CDP 注入登录态，对控制台 / 监控状态 / 用户列表 / 告警规则 / 会话审计 / 登录页
逐页截图，明暗两套主题都过了一遍。

**设计语言梳理**：`admin-design-language.md` 重写为完整规范（定位 / 七条原则 / 页面主次配方 /
色彩 / 微色阶 / 排版尺度 / 圆角间距 / 组件规范 / 壳组件 / 主题 / 自查清单）；代码侧统一了三处：
控制台、监控状态、监控指标的手写页头改为 `PageToolbar`（标题 18px medium + 13px 说明，与列表页一致）；
`Tag` 的历史色名（blue / cyan / gold / purple …）全部折算到语义色与品牌色，界面不再出现 antd 装饰色；
AI 会话页左侧列表栏改 `--surface-3`，与对话区分离；指标磁贴的陈旧标记补「陈旧」文案（颜色 + 文字成对）。

**监控指标页重做**：原来是一列「时间 + 横条 + 数字」的流水（60 行柱子读不出趋势，也回答不了「现在多少」）。
改成以指标为中心的三层：主 = 当前值 + 环比 + 趋势面积图（区间 60 窗口）；次 = 最小/平均/最大/样本数 +
最近 15 个窗口明细（带表头、值、带符号环比，最新一行高亮）；辅 = 类型 / 单位 / 采集窗口 / 作用域 / 依赖
一行小字。顺带修了两个问题：页面容器是 `h-full` 的 flex 列，Card 带 `overflow-hidden` 会被压扁
（图表被截掉下半截），卡片补 `shrink-0`；明细表里的环比负数漏了负号。

**表单控件收口**：admin 里残留的 3 个原生 `<select>`（会话页 agent、指标页指标、规则表单选项）、
2 个原生 `<button>`（模型选择器重试、控制台 7/30 天切换）与审计页两个行按钮全部换成组件库的
`DictSelect` / `Button`；7 处 `<label>` 换成 `Label`；状态色（emerald / amber / red / blue / cyan）
统一为语义 token。

**逐页重做**：
- 实时告警：一片空白 → 四个状态磁贴（连接 / 已接收 / 窗口占用 / 最近事件）+ 事件流卡片与像样的空态
  （图标 + 说明 + 触发测试按钮），去掉斑马纹；
- 工具配置：三条 Alert 说明从首屏沉到表格下方并默认折叠（参考材料不占主内容），限额列从三行
  「不限/不限/用默认」改成只显示被覆盖的项（全默认时一个「默认」），去掉与 key 列重复的「复制 key」；
- 模型管理：首次进入自动选中第一个供应商（不再一进来就是空表），「同步失败原因」列合并到「最后同步」
  下方（该列常年为空），输入模态多标签改单行文本，操作列收窄不再溢出；
- 个人中心：设备列表去斑马纹、本机标签改语义色；用户 / 管理员列表的邮箱升为主信息；
- 会话页空态：加图标与更大标题；侧栏与对话区用面层分开。

**菜单图标去重**：侧栏里「告警记录」和「监控指标」原本都用 `ActivityIcon`，「审计与复盘」用的 `SparklesIcon`
语义也不贴。现在按职责分开：告警记录 `ScrollTextIcon`（记录）、监控指标 `ChartLineIcon`（趋势）、
审计与复盘 `HistoryIcon`（复盘）；搜索面板的页面清单改为**从侧栏 `MENU_ITEMS` 派生**（图标 / 文案 / 路由
只有一份），并补上此前缺的 AI 页面与实时告警，同时遵循用户体系开关隐藏系统设置。

**侧栏改悬浮胶囊**：`Sidebar` 用 `variant="floating"`，白面、圆角 2xl、四周 12px 留白，靠面层差浮起
（不加投影）；折叠态是同一块胶囊收窄成图标导轨。深色下 `--card` 比页面底亮一档，仍然可辨。
