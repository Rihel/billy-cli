## 22:26 去掉 DbService 的 AppLogger 依赖

- 做了：删掉 `@Inject(AppLogger)` 与 `printSql`，`DbService` 现在只依赖 `Db`；SQL 调试只留
  `getFullSqlStatement`（要打日志由调用方用自己注入的 logger 打）。测试同步去掉 logger 替身。
- 坑点：这个依赖是照 rihel 抄 `printSql` 时顺手带进来的，从没验证过它是否必要。
  一核对才发现 kits 里 13 个注入 AppLogger 的类，其它都有 3~5 处运维日志
  （连接 / 重试 / 生命周期），只有 DbService 是 1 处 debug 且属于调用方动作；
  另外 `object-storage.ts` 也是注入但 0 处使用（同一个味道，暂未动）。
- 解决：立个判据——门面要不要 logger 看它**自己是否产生运维日志**；不产生就不注入。
  DbService 的 SQL 打印机会成本只是调用方多写一行 `this.logger.debug(...)`，
  而 repository/service 本就注入了 AppLogger。rihel 的 `printSql` 是唯一没搬的方法。
