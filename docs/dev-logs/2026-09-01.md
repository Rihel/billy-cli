## 20:00 修复 admin 退出登录失效

- 排查：菜单点击链路（base-ui MenuItem onClick 链式执行）、后端 /admin/logout（幂等免鉴权）、
  cookie 删除（logoutAction finally jar.delete）均正常；问题最可能在「server action 删除 cookie 后
  立即 router.replace 客户端导航」——客户端路由缓存可能携带旧 cookie，导致退出后被 proxy/SSR
  守卫弹回后台（表现为「没法退出」）。
- 修复：AppHeader.exit 改为并行清理（Promise.allSettled([removeToken(), logoutAction()])，
  任一失败不阻塞）+ `window.location.href = '/auth/login'` 全量导航，保证新请求必然携带
  已删除的 cookie。
- 验证：admin tsc 零错误、next build 成功。
