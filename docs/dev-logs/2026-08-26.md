## 01:25 认证鉴权设计修复：服务端会话（Redis）

- 做了：用户拍板「会话存 Redis、每请求查」。新增 SessionStore 门面（create/verify/revoke/revokeAll，key `auth:session:{sha256(token)}` + 索引 `auth:index:{type}:{sub}`）；AuthService/AdminService 登录建会话、verifyToken 查会话、新增 logout；UserService/AdminService 禁用/删除时 revokeAll 踢人；/auth/logout、/admin/logout 幂等路由 + SDK + admin/web logoutAction。
- 坑点：旧 token 无会话，改造后全部强制下线需重登（一次性可接受）；logout 若挂鉴权中间件，onUnauthorized 调它会造成 401 死循环。
- 解决：logout 路由不挂鉴权、幂等（token 有效删会话，无效也成功），前后端登出/401 都安全。实测：禁用/登出后旧 token 立即 401（修复前 200），双体系隔离完好；admin 侧踢人同样生效。设计文档：docs/design/auth-session.md。
