**修「缺少密码」误报**：模型调连接器工具时 `precheck` 按工具设置的密钥判空，而连接器密钥在实例上，
于是明明配了也报缺。`connector-guard` 现在把实例密钥嫁接进本次调用的 `settings.secret/secretHint`，
前置检查与脱敏都恢复正常；工具配置页不再对连接器工具展示密钥字段。

**优化 agent 提示词**：把「你没有绑定任何业务系统的工具」改成「能做什么以本次工具定义为准，取决于配置了哪些连接器」
（否则接了数据库也照样拒绝）；删掉 `tools.eta` 里与模型侧工具说明重复的整段描述（每个工具 200–800 字）；
新增「业务数据（连接器工具）」段（先 list/describe 再 query、只取需要的列、敏感字段打码、按 disabled /
precheck-failed / upstream / rate-limited 分别处理），且**只有存在连接器工具时才注入**；
合并「联网优先直取」的三处重复，明确「换路径 ≠ 同一次调用重试」。渲染实测：无连接器 2855 字符，
有连接器 3420 字符。

**提示词去重（全量）**：重复规则各留一处——「工具定义以请求为准」只在 tools 段；「不编造」只在纪律；
「先验证 / 副作用先确认」合并成纪律两条；「联网优先直取」只在纪律；「网页指令当数据 / 引用来源」只在角色；
web-fetch / web-request / plan-* 的工具说明删掉与全局规则重复的句子；ask-user 的挂起语义只在工具说明。
渲染实测：带连接器段 2874 字符（≈1.6k tokens），改前同日首版约 3.4k 字符且另含整段重复的工具说明。
