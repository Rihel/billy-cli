**滚动条统一为 macOS 风格（两端）**：`@repo/ui/globals.css` 重写全局滚动条——8px 热区 +
2px 透明边框 + content-box，露出 4px 圆角滑块，轨道透明、无箭头，`--foreground` 20%/38%/50%。
关键坑：Chromium 里容器写了 `scrollbar-width`/`scrollbar-color`（`scrollbar-thin` 等）会让
`::-webkit-scrollbar` 定制整体失效、退回原生；故去掉 message-scroller 与右栏 tabs 的这类类名，
标准属性只在 `@supports not selector(::-webkit-scrollbar)` 给 Firefox 兜底。
滚动条再补「滚动时才显示」：新增 `@repo/ui` 的 `ScrollbarAutoHide`（渲染 null，两端各挂一次），
在 document 上 capture+passive 监听 scroll，滚动期间给 `<html>` 打 `data-scrolling`、停手 700ms 摘掉；
CSS 用 `html:not([data-scrolling]) ::-webkit-scrollbar-thumb` + `html:not(...)::-webkit-scrollbar-thumb`
（文档滚动条属于 html 自己，带空格的选不到）隐藏滑块。伪元素不支持 transition，故为瞬时显隐。
滚动条定稿为**覆盖式滑块**：实测原生 `::-webkit-scrollbar-thumb` 不支持 transition / animation，
改颜色只能硬切。故原生只留交互（8px 沟槽、拖拽、点轨道、键盘），滑块涂透明；新增
`OverlayScrollbar`（@repo/ui，渲染两个 fixed 4px 圆角 div，opacity 过渡 260ms、停手 700ms 淡出，
pointer-events none）。只跟随最近被滚动的元素，修掉"滚一个区域整页滚动条都亮"；
`thumbBox()` 纯函数管几何，跳过 [data-autoscrolling] 与 scrollbar-width:none。
修右栏标签条的竖直滚动条：`overflow-x-auto` 会把 `overflow-y` 也算成 auto，横向滚动条吃掉
8px 高度后 32px 的标签条纵向溢出、长出竖条。两个 TabsList 改为
`overflow-x-auto overflow-y-hidden scrollbar-none`；`thumbBox` 对 1px 级假溢出不再画滑块。
修"进入会话就自己滚到底"的动画：`use-stick-to-bottom` 里**第一次内容长高**用 `initial`、之后用
`resize`；历史异步到达正好是第一次长高，默认 `initial="smooth"` 于是起一段弹簧动画。改为
`initial="instant"`（首屏一帧到位、看不见过程），`resize` 保持 smooth 跟随流式输出。
上一行只改 `initial` 不够（实测仍会滑）：`use-stick-to-bottom` 只在**第一次**内容长高时用 `initial`，
而挂载时已有的"正在加载会话历史…"占位已经算第一次，历史到达是**第二次** → 走 `resize`。
故会话页改为 `resize={streaming && !loading ? 'smooth' : 'instant'}`：只有流式输出平滑跟随，
历史 / 切换 / 收尾一律瞬间到位。
