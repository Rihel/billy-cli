## 03:00 侧边栏间距改由组件 className 控制（修复 CSS 覆盖失效根因）

- 背景：用户反馈「还是没间隔」。根因：之前的覆盖写在 @layer base 内，Tailwind v4 的 utilities 层声明在后、
  层顺序优先于特异性，.gap-0 / .p-2 等默认类始终压过我的覆盖，规则从未生效。
- 反思：能用组件 className 的不该用 CSS 覆盖。间距类（shadcn 组件不可改，但业务组件可改）：
  ① AppMenu.tsx：SidebarGroup className="py-1.5"（组间 12px）、SidebarMenu className="gap-2"（项间 8px）、
  SidebarMenuButton className="py-2"（项高 32px）、SidebarGroupLabel className="h-7 text-[11px] tracking-[0.08em] opacity-45"；
  ② DataTable.tsx：TableHead className="h-9 px-3 text-xs font-medium text-muted-foreground"、TableCell className="p-3"。
- globals.css 清理：删除 @layer base 内所有失效覆盖；仅保留必须 CSS 的规则（激活指示条伪元素、主按钮 hover 加深 +
  橙色阴影、滚动条、mono tabular-nums），并移出 @layer（非 layer 规则优先于所有 layer，含 utilities）。
- 验证：admin tsc 零错误、next build 成功、产物确认 gap-2/py-2/py-1.5/h-7/tracking 等类与激活指示条均已编译。
