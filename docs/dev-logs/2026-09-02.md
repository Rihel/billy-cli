  SidebarMenuButton className="py-2"（项高 32px）、SidebarGroupLabel className="h-7 text-[11px] tracking-[0.08em] opacity-45"；
  ② DataTable.tsx：TableHead className="h-9 px-3 text-xs font-medium text-muted-foreground"、TableCell className="p-3"。
- globals.css 清理：删除 @layer base 内所有失效覆盖；仅保留必须 CSS 的规则（激活指示条伪元素、主按钮 hover 加深 +
  橙色阴影、滚动条、mono tabular-nums），并移出 @layer（非 layer 规则优先于所有 layer，含 utilities）。
